# README images

The top-level `README.md` references three images. Capture them from a running
StackPulse and drop them here with these exact filenames. Until they exist,
GitHub shows the images' alt text.

Shoot on a Retina display, then keep the file widths reasonable (≤ 2× the display
width in the README) so the repo stays light.

| File | What to capture | Notes |
| --- | --- | --- |
| `hero.png` | The **menu-bar popover** — the money shot. | Open it when you have live limits showing, at least one active session, and today's spend. This is the first thing a visitor sees; make it representative. |
| `dashboard.png` | The **main window** on Home or Overview. | Per-provider spend + live limits + a trend. Light *or* dark — pick whichever reads cleaner. |
| `diagnostics.png` *(optional)* | The **Diagnostics** screen. | Only if you add a third shot to the README; the "is it working" screen is a strong differentiator. |

Tips for a professional look:
- A clean menu bar (hide clutter) and a neutral desktop behind the popover.
- Real-but-unremarkable numbers. Nothing here should expose a private project name
  you don't want public — the app shows folder names, so tidy the watched folders
  first, or use a demo/sample run.
- Consistent light/dark across the set.
